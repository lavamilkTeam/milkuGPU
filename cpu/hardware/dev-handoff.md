## 当前决定

- 项目名 Lavaneko，不再使用 SunPower。默认 16 位 CPU；仓库仍包含 32 位仿真作为已有成果。
- 目标八块功能板，加一块集中供电板；每块不超过 100×100mm，纵向堆叠。牢固插接，不使用杜邦跳线。
- 立创商城选型，优先国产品牌、国内现货和低价格。用户允许非 74 的成品功能 IC。
- 主 ALU、乘法器、除法器独立。新的优化方向是各乘除单元内部复用自己的加减电路做符号处理，采用多周期控制，不借用主 ALU。
- 当前约 200 颗仅为优化目标，不是完成的 BOM，且此前未包含新增加的 VGA/键盘/软盘功能。八板目标也需要真实布局核算。
- 键盘、VGA、串口和软盘支持是用户新增要求。仍待确定：PS/2 或 USB 键盘；文字终端或彩色像素图形；34 针传统软驱、现成串口软盘控制器还是 USB 软驱。不得把普通 UART 当成传统软驱控制器。

## 已有成果

- `logisim/projects/Lavaneko16.circ`、`Lavaneko32.circ`：可运行的独立乘除法 CPU 仿真。
- `cpu/isa`：ISA 与模型；`logisim/circuits`：电路生成；`logisim/cli`：构建/验证入口。
- `docs/architecture.md`：详细架构、时序与指令；`docs/Lavaneko-架构与指令集.pdf`：介绍 PDF。
- `docs/Lavaneko-架构总览.svg`、`.png`：架构图。
- `cpu/hardware/build-plan.md`：最新九板目标、接口与选型进度。
- `cpu/hardware/implementation-evaluation.md`：旧仿真直接映射约 300 颗的评估，是比较基线，不是最终采用的优化版 BOM。
- 本机上一次完整检查 `npm run check` 通过：13 项测试、9848 条 Logisim 向量。目标机需要按本机环境安装相应运行依赖后再运行，不能把旧结果写成目标机实测。
