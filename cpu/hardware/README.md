# 实体硬件约束

当前实体实施入口：[浏览器 EDA 实施记录](build-plan.md)。用户已选择八块功能板加一块集中供电板，并新增键盘、VGA 和串口／软盘需求。

- 项目名 Lavaneko。
- 单块 PCB 外形不超过 100×100 mm，纵向堆叠。
- 优先考虑容易焊接和维修的小封装成品功能器件；允许使用功能合适的非 74 系列器件。
- 16 位加减器优先使用四个 4 位加法器级联，配合条件取反及进位输入实现减法。
- 乘法采用独立移位累加单元，除法采用独立移位试减单元，均有自己的加减电路、寄存器和硬件控制，不复用主 ALU。
- 有符号运算包括补码与幅值转换；当前仿真使用额外的取负电路，实际器件数量需计入这些电路及 HI/LO 状态寄存器。
- 不使用 MCU、FPGA 或隐藏的软件组件代替 CPU 的执行逻辑。
- PCB 工作开始前必须应用 pcb-routing-standards。

16 位、3.3V 实现的器件预算、封装取舍和堆叠安排见 [实体实现评估](implementation-evaluation.md)。该评估用于安排工程规模，最终 BOM 和板数由引脚级原理图及布局确定。
