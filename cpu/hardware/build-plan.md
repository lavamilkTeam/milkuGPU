# Lavaneko 浏览器 EDA 实施记录

## 用户要求

- 在嘉立创 EDA 专业版浏览器编辑器绘制。
- 八块功能板，加一块集中供电板；每块 PCB 不超过 100×100mm，纵向堆叠。
- 板间连接牢固，不使用杜邦跳线。
- 在立创商城选型，优先国产品牌、国内现货和低采购成本。
- 支持键盘、VGA 显示器及串口；需要连接软盘设备。
- CPU 保留 16 位并行、多周期执行，乘法器、除法器不借用主 ALU；符号处理改为各单元内部多周期复用。

## 规模与模块安排

之前约 200 颗是优化 CPU 的目标，未包含新增加的显示扫描和完整外设控制；八块功能板也不是已有布局结果。原仿真仍是独立展开符号处理的版本，不能直接据此转 PCB。先完成优化数据通路、启动初始化和控制时序，再确定芯片数量。

九板目标按下面的分组进行原理图规划；不将分组表当作已经布通的 PCB。

| 编号 | 内容 |
|---|---|
| P0 | 集中供电、输入保护、各板支路保护和电源监测 |
| B1 | PC、程序存储器、指令寄存器 |
| B2 | 指令译码、多周期控制、复位与启动序列 |
| B3 | 通用寄存器、顺序读取与总线接口 |
| B4 | 主 ALU、操作数暂存、标志 |
| B5 | 独立乘法器 |
| B6 | 独立除法器 |
| B7 | RAM、架构可见 HI/LO、键盘和 UART 接口 |
| B8 | VGA 扫描、显示存储和输出接口 |

B5/B6 的选择网络、B7 的外设数量以及 B8 的显示规格是空间风险最大的部分，先做这些板的代表性布局核算。软驱控制器的归属取决于实际设备接口；不能把它无预算地塞进 UART。

## 板间通信与机械连接

采用低速 16 位并行系统总线；各板上的运算迭代留在本板。板间寄存器传送分周期完成，避免贯穿堆叠的多套并行操作数总线。接口需有地址、数据、读写、选通、就绪、复位与中断等信号。

机械首选板对板插接并用四角螺柱固定。螺柱承担支撑和抗拔，连接器承担电接触；不靠连接器摩擦力支撑整机。选型必须同时确认母座、对应公针、有效插合长度、插合后板间距离、接触电流、焊盘和装配工具空间。

如果常备库存中找不到合适的堆叠长脚组合，则采用带锁扣牛角座及 IDC 整排排线。IDC 是带防反插和机械保持的整排电缆，不是杜邦跳线。排线长度、各板短支路、时钟边沿与回流地须共同核算。

普通短脚排母只能作为价格参考，不能直接认定为堆叠连接器。也不能仅凭“2×20”就冻结总线针数；完整信号分配及回流、电源触点预留后再定连接器数量。

VGA 的像素时钟和模拟 RGB 留在 B8，不经过 CPU 长总线。调试初期降低 CPU 时钟，仍检查快速逻辑边沿造成的反射与过冲。

## 集中供电

P0 为八块功能板提供电源。CPU 主逻辑暂按 3.3V，键盘或外设所需 5V 通过单独电源支路提供，信号进行相应电平转换。输入电压、转换芯片及额定电流在整机功耗和软驱型号明确后冻结。

八个支路独立安排保护与足够的回流导体；避免让最后一块板的电流流过前面所有板的细走线。若经连接器并联触点送电，按降额及电流分配核算，不能直接把单针额定电流相加作为整机保证。

软驱电机与逻辑电源分支隔离处理，检查启动浪涌；是否需要 12V 由软驱型号决定。VGA 地、数字地采用有连续回流路径的公共地结构。外部带电信号不得通过 IO 给断电 CPU 反向供电。

## 外设规格等待用户答复

1. 键盘采用 PS/2，还是普通 USB 键盘。前者适合简单硬件；后者需要 USB 主机控制器和枚举/HID 驱动，不能只安装 USB 插座。
2. VGA 是文字终端，还是需要彩色像素图形。扫描须有独立时序及显示缓存；CPU 停机或执行乘除法时图像仍须稳定。
3. 软盘设备是传统 34 针软驱、现成串口控制设备，还是 USB 软驱。传统软驱不是 UART 设备，需要控制、编码和数据恢复路径；USB 软驱也不能假定与普通 U 盘协议完全相同。

串口考虑国产 WCH 专用 UART，不能用 USB 转串口芯片冒充 CPU 并行总线 UART。CH432 系列提供双 UART，具体封装支持的主机接口必须按对应引脚表确认。[WCH 官方选型表](https://www.wch.cn/products/productsCenter/otherChip?categoryId=69)

CPU 目前没有外设地址译码。实施时需增加 IO 访问和就绪处理；若采用内存映射，需要明确保留的 RAM 地址窗口。显示可通过地址寄存器和数据端口访问，避免要求现有 CPU 立即增加寄存器间接寻址指令。此处不预先冻结地址表。
