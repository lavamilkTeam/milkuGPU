# Lavaneko 16 位实体实现评估

日期：2026-10-06。依据当前 `logisim/projects/Lavaneko16.circ`、电路生成源码及文末厂商资料。

## 建议方案

采用 3.3V 供电、HC 功能逻辑加 LVC 接口缓冲、SOIC/TSSOP 混用、并行 Flash 与 SRAM。保留四个通用寄存器、双读口、独立乘除法、完整有符号运算和 HI/LO。首版按约 300 颗 IC、10～12 块 100×100mm 板安排空间，先按 11 块划分模块。

这是保留当前并行数据通路的一种实现预算，不是这套指令集所需的最少芯片数。小封装主要减少占板面积；减少芯片数量还需要改变寄存器组织、选择网络或运算时序。本次只记录评估，不改变现有仿真电路及指令集。

## 器件选择

| 功能 | 首选候选 | 选择依据 |
|---|---|---|
| 加减运算 | CD74HC283，SOIC-16 | 四位加法器级联；16 位使用四颗 |
| 数据与状态寄存器 | CD74HC173，TSSOP-16 或 SOIC-16 | 四位存储，自带写使能和异步清零 |
| PC、迭代计数 | SN74HC161 | 四位计数器级联；PC 需四颗 |
| 二选一 | SN74HC157 | 每颗处理四个数据位 |
| 四选一 | SN74HC153 | 每颗处理两个数据位 |
| 条件取反 | SN74HC86 | 每颗四个异或门 |
| 标志与控制 | HC74、HC00/02/04/08/30/32/138 等 | 按使能、译码、比较和时钟要求组合 |
| 板间与存储器缓冲 | SN74LVC244A；双向场合考虑 LVC245A | 电平、负载和总线方向分别核算 |
| 程序 ROM | 4 × SST39VF010 | 每颗 128K×8；使用低 64K 地址，合成 64K×32 指令 ROM |
| 数据 RAM | 2 × AS6C1008 | 每颗 128K×8；使用低 64K 地址，合成 64K×16 RAM |

HC283、HC173 可在 3.3V 工作。HCT 不能因为编号相近就替换到 3.3V 方案中。具体订货后缀必须对应所选封装、电压及温度范围。[HC283](https://www.ti.com/lit/ds/symlink/cd74hc283.pdf)、[HC173](https://www.ti.com/lit/ds/symlink/cd74hc173.pdf)

SOIC 优先用于手焊难点，TSSOP 用于重复、易接近的逻辑阵列；不给全部器件强行选择最小封装。存储器可做可拆卸小板，方便编程与返修。这里没有把供应商现货、价格或替代料资格视为已确定。

### 为什么不直接换成一颗 16 位寄存器

SN74LVC16374A 确实能存 16 位，但没有数据写使能和异步复位。它的 OE 只控制输出是否高阻，不能阻止寄存器在时钟边沿更新。[厂商功能表](https://www.ti.com/lit/ds/symlink/sn74lvc16374a.pdf)

若用反馈选择器补写使能，一个 16 位寄存器需要一颗 16374 加四颗 157，共五颗，仍须另外处理复位。四颗 173 已具备这些存储控制功能。通过专门的时钟门控和启动初始化可以重新优化，但不能直接把 16374 当作现有寄存器的等价替换件。首版建议保留 173 路线。

## 芯片预算如何得到

从顶层 Lavaneko 展开子电路，不重复计入 CPU_Test：当前有 47 个四位加法器实例，其中两个用于迭代计数；另有一个 16 位 PC 加法器。实体 PC 和迭代计数器改用 161，数据运算仍需 45 颗 283。

| 加法器用途 | 四位加法器数量 |
|---|---:|
| 主 ALU | 4 |
| 乘法移位累加核心 | 4 |
| 除法试减核心，17 位填充到 20 位 | 5 |
| 乘法输入幅值转换，两个 16 位 | 8 |
| 乘法 32 位结果符号修正 | 8 |
| 除法输入幅值转换，两个 16 位 | 8 |
| 除法商、余数符号修正，两个 16 位 | 8 |
| 合计 | **45** |

也就是说，真正的主 ALU 与乘除法迭代核心合计只占 13 颗加法器；当前完全展开的符号处理占另外 32 颗。

实体预算采用局部等价化简：条件取负写成 `(x XOR 全位复制的 NEG) + NEG`，在对应位宽内截断。这样仍各用各的加法器，但省去原条件取负电路的部分选择器。固定移位使用连线；常量补位不计入动态选择通道。

| 器件 | 分配预算 | 包含范围 |
|---|---:|---|
| HC283 | 45 | 数据加减及所有符号处理 |
| HC86 | 36 | 128 位条件取负加 16 位主 ALU 减法输入 |
| HC173 | 57 | 通用寄存器 16、IR 8、HI/LO 8、乘法状态 12、除法状态 13 |
| HC161 | 6 | PC 4、乘除迭代计数各 1 |
| HC74 | 8 | 小宽度状态存储；使能外围另计 |
| HC153 | 24 | 两个寄存器读口 16、最终写回四选一 8 |
| HC157 | 59 | 乘法 12、除法 22、顶层操作数及结果选择 25 |
| HC04 | 3 | 除法试减的 16 位除数取反；其他反相放入控制预算 |
| 上述数据通路小计 | **238** | 已做常量化简与条件取负替换的映射预算 |
| 译码、比较、使能、复位、清 RAM 与控制外围 | 30～45 | 最终数量取决于门的合并与芯片内打包 |
| 存储器及板间缓冲、时钟分配 | 10～16 | 含 SRAM 读缓冲；不能与接口部分重复计数 |
| ROM + RAM | 6 | 四颗 Flash、两颗 SRAM |
| 时钟源、复位监控 | 2 | 型号待按时序选择 |
| 合计 | **286～307** | 电源转换 IC 另计；工程预算取约 290～310 颗 |

该数量范围依赖上述映射；它不是上下界保证。完整引脚级综合可能进一步合并逻辑，也可能需要更多扇出缓冲。无源器件、LED、连接器和测试点不包含在 IC 数量内。

## 3.3V 存储器接口

Flash 的 A16 固定为零；四颗并行组成一个 32 位指令字。程序镜像按四个字节通道分别编程。VF 系列的电压范围是 2.7～3.6V；不能混用名称相似的 5V SF 系列。[SST39VF010 数据手册](https://ww1.microchip.com/downloads/aemDocuments/documents/MPD/ProductDocuments/DataSheets/SST39LF010-SST39LF020-SST39LF040-SST39VF010-SST39VF020-SST39VF040-Data-Sheet-DS20005023.pdf)

SRAM 的 A16 也固定为零。两个字节通道共用地址和读写控制；读写切换需留输出关闭时间，避免 SRAM 和 CPU 同时驱动数据线。[AS6C1008 数据手册](https://www.alliancememory.com/wp-content/uploads/pdf/AS6C1008_Mar_2023V1.2.pdf)

AS6C1008 的 VOH 最低保证为 2.4V（指定负载条件）。按 HC 的高电平输入要求约 0.7VCC 计算，在 3.3V 时只剩约 0.09V 静态余量；若电源为 3.3V+5%，要求约 2.426V，已高于该输出保证。因此 SRAM 读方向预留两颗 LVC244，再接 HC 数据通路。LVC244 在 2.7～3.6V 供电时 VIH 要求为 2.0V；其输出到 HC 的负载与电平仍须核算。[LVC244 数据手册](https://www.ti.com/lit/ds/symlink/sn74lvc244a.pdf)

Flash 与 SRAM 不能一概而论：这里所选 Flash 在 100µA 输出负载下给出 VOH≥VDD−0.2V，可以按实际扇出评估直接连接 HC。跨板或大电容负载仍可加缓冲，但理由是负载与信号质量，不是将其误认为同样只有 2.4V 输出保证。

真实 SRAM 没有整片瞬间清零输入。为保持当前复位后 RAM 为零的行为，实体硬件应在释放运行前顺序写零 65536 个地址，期间禁止取指；可以借用 PC 作清零地址计数器，结束后 PC 归零。若每时钟写一个字，100kHz 时至少约 0.66 秒，10kHz 时至少约 6.55 秒，实际还要计入控制开销。

## 100×100mm 堆叠规划

为易焊接与返修，先按 IC 单面安装、SOIC/TSSOP 混合、四层板安排。单板左右各预留约 12mm 给接口及机械边界，上下各预留约 8mm，剩余约 76×84mm。该尺寸是空间预算，连接器确定后重新计算。

以每颗 SOIC-16 约 14×11mm、TSSOP-16 约 11×10mm 的布局单元估算，单元包括焊盘、去耦与工具空间；再留约 35% 的有效区域作公共走线和电源通道。两种封装大致各半时，约可安排 30 颗普通逻辑 IC。存储器板、大连接器板和高扇出控制板需要单独计算。

据此建议预算 **10～12 块板**，以以下 11 块功能分组开始布局：

| 功能组 | 板数预算 |
|---|---:|
| PC、ROM、IR、译码、时钟与主控制 | 2 |
| 四个通用寄存器及双读口 | 1 |
| 主 ALU 与操作数选择 | 1 |
| 乘法输入处理及迭代核心 | 2 |
| 除法输入处理、异常检测及迭代核心 | 2 |
| 结果符号修正、HI/LO 与写回 | 2 |
| RAM、供电接口与调试接口 | 1 |
| 合计 | **11** |

模块边界需随实际走线拥堵调整。按板间节距 15～18mm，加最外侧器件及支撑空间，10～12 块的整机高度约 **15～22cm**。这不是布局证明，也不是能做到的最小体积；它是优先方便手焊和维修的空间安排。

板间先分配信号再确定连接器。仅 A、B、写回三条 16 位总线就有 48 根信号，还要地址、控制、时钟、电源和地；乘除法中间状态尽量留在各自相邻板上，不把所有宽总线都贯穿整个堆叠。连接器必须预留充足回流地，不能只按信号根数选针数。

## 时钟和布线安排

- 首次调试从单步、10kHz 开始，再以 100kHz 为初期目标；最高频率由实际电路时序决定。
- 核算完整路径：寄存器输出、输入选择、进位链、结果选择、目标寄存器建立时间、跨板延迟和时钟偏斜。上升沿取指、下降沿执行的路径按半周期预算。
- HC 数据手册常列 2V、4.5V、6V 时序，不能把典型值插值当作 3.3V 的最大延时保证。除法试减和长位宽符号修正是重点路径。
- 主时钟和反相时钟由专用分配路径驱动；不能直接用组合译码与门截断时钟。单步按钮消抖；复位释放检查恢复与移除时间。
- 每颗 IC 近端去耦；负载电流、动态功耗和连接器压降确定后再定电源容量。LED 经缓冲显示，避免直接增加数据总线负载。
- 按 PCB 规范保留连续地参考、45°走线和主干 3W 中心距；实际边沿与叠层决定阻抗、终端与等长要求。LVC 边沿较快，低时钟频率也要检查跨板反射。

下一步应先画一块代表性的寄存器或 ALU 板，做引脚级连接与试布局，用实际焊接空间和走线占用修正全机板数，再展开全部板卡。
