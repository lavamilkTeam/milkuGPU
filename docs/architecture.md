# 架构

基线：`lavamilkTeam/lavanekoCPU@8e249ae491903985db7ca79df683efa5b7946267`。
参考接口：基线 `cpu/isa/index.js` 的 `isa.encode / isa.execute / isa.trace`。

| 项目 | 当前实现 |
|---|---|
| 数据宽度 W | 16 或 32，默认 32 |
| 指令宽度 | W+16；分别为 32、48 位 |
| 寄存器 | REG1..REG4，各 W 位；编码索引 0..3；均可写 |
| PC | 16 位，按完整指令计数；65535+1 回绕到 0 |
| 数据地址 | 16 位，按 W 位数据字寻址；没有字节使能 |
| 标志 | Z 零、C 加法进位／减法无借位 |
| 乘除状态 | HI、LO 各 W 位；MD_ERROR 两位 |
| 执行 | 单发射、顺序提交；不重叠取指和执行 |
| 复位 | 高有效，同步上升沿；清零核心状态和四个寄存器 |

## 控制字段

| 位 | 含义 |
|---|---|
| 0 | 减法选择 |
| 1 | 通用寄存器写入 |
| 2 | 从数据存储器选择写回值 |
| 3 | 数据存储器写入 |
| 4 | 无条件跳转 |
| 5 | B 操作数置零 |
| 6 | 停止 |
| 7 | A 选择寄存器；为 0 时选择立即数 |
| 9:8 | B 寄存器索引 |
| 11:10 | 目标寄存器索引 |
| 13:12 | A 寄存器索引 |
| 14 | 更新 Z/C |
| 15 | 根据提交前的 Z 条件跳转 |
| W+15:16 | W 位立即数 |

普通算术：`A = bit7 ? Ra : immediate`；`B = bit5 ? 0 : Rb`；按 bit0 加减。结果截断至 W 位。RAM 地址和跳转目标为立即数低 16 位。加载数据不改变 ALU 的 Z/C 计算来源。

bit7:6=`11` 时，低八位切换为乘除扩展操作码，优先于上述控制位；扩展不得触发旧式 RAM、HALT、分支或标志副作用。保留扩展码执行 NOP，PC 加一。普通 HALT 优先于普通控制字的其他效果。

## 乘除单元

移位累加乘法和移位试减除法共用一个请求／结果接口；不使用主 ALU。乘法内部为 2W 位累加器，除法内部为 W+1 位余数。RTL 未使用乘法或除法运算符推断组合乘除器。

- MULU/MUL：完整 2W 位乘积写 HI:LO，目标寄存器得到 LO。
- DIVU/DIV：商写 LO，余数写 HI，目标寄存器得到 LO。
- 有符号除法朝零截断；余数符号与被除数一致。
- 正常完成清零 MD_ERROR；全部扩展保留 Z/C。
- 除数为零：MD_ERROR=1；MIN/-1：MD_ERROR=2；两者均保持目标寄存器、清零 HI/LO，并继续下一条指令。

正常运算从接收请求沿到产生结果沿共 W+2 个上升沿（含接收沿）；错误除法为两个沿。结果保持到 `result_ready`。核心另用一个沿提交该结果。

## 时序与兼容范围

无等待普通指令：取指沿、执行／提交沿，共两拍。加载／存储增加一个数据握手沿。正常乘除指令在存储器无等待时占 W+4 拍：取指一拍、单元 W+2 拍、提交一拍。错误除法共四拍。外部等待可延长取指或数据访问。

指令结果兼容基线，不保持 Logisim 的上升沿取指／下降沿执行方式。乘法和除法在本移植中共用一个模块及部分状态，不照搬原版两套独立单元。取指和数据访问改为 valid/ready 接口。

复位不清除外部 RAM，不取消已经握手完成的外部写事务。测试从零初始化 RAM，对应原模型初始状态；系统若要求“复位清空内存”，必须在存储器适配器实现。复位期间外部接口 valid 为零，未完成请求被撤销；处理器与适配器须协同复位。

本次未改变指令编码、增加寄存器、加入 SIMD／GPU 指令；无浮点、缓存、异常向量、中断、栈约定或虚拟内存。
