# 验证

在 macOS Apple Silicon、Logisim-evolution 5.0.0 上运行 `npm run check`。

| 测试对象 | 16 位 | 32 位 |
|---|---:|---:|
| AddSub | 256 通过 | 256 通过 |
| RegisterBank | 28 通过 | 28 通过 |
| MultiplyUnit | 1526 通过 | 2806 通过 |
| DivideUnit | 1430 通过 | 2614 通过 |
| CPU_Test | 372 通过 | 532 通过 |

总计 9848 条原生仿真向量，另有 13 项 Bun 测试。

- 加减测试包含零值、全 1、借位、溢出及跨 4 位边界的进位。
- 寄存器测试包含非顺序写入、所有双读口组合、禁止写入和复位。
- CPU 测试包含上升沿取指、下降沿执行、任意目标寄存器、RAM 往返、条件与无条件跳转、循环、停机保持和复位。
- 乘除模块覆盖正负数、零、最大值、最小有符号数、全宽乘积、余数符号、除零及 MIN/-1 溢出。运算中改变输入与重复 START 不改变已接受的操作，DONE 保持到 ACK，并检查连续操作和运行中复位。
- CPU 增加连续乘除、等待期间 PC/IR 与寄存器保持、HI/LO 写回和读取、状态读取、错误恢复、乘法期间复位重启的逐沿检查。
- 参考执行模型提供 CPU 逐步状态的预期值；原生 Logisim 加载实际生成的电路进行比较。
- 格式与包依赖检查通过。另用临时非法跨包内部导入确认边界规则确实会失败，随后移除该临时文件并重新验证通过。

`.txt` 为可重复使用的测试输入，运行产生的 `.log` 不纳入 Git。上述检查针对数字功能正确性，不验证真实 74 芯片传播延迟、负载或板间信号完整性。
